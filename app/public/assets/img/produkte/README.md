# Produktabbildungen

Unveränderte Kopien aus dem bereitgestellten Projektordner `Anleitungen/Produkte Bilder`.
Die Zuordnung in `assets/js/produktbilder.js` erfolgt über Produktnamen: WiPro III und safe.lock sowie GPS-pro und Pro-finder teilen im Katalog Slugs, aber keine Bilder.
Abbildungen zeigen die Produktfamilie; Ausführung und Farbe können abweichen. Produkte ohne eindeutiges Bild behalten einen neutralen Platzhalter.
