# Terminologie et graphies — termes de référence pour les utilisateurs et l’IA

Cette page définit la terminologie obligatoire du wiki français. Elle sert de référence commune au support, à la documentation, à la rédaction et aux agents IA. Le terme source allemand n’est indiqué que pour assurer une correspondance sans ambiguïté.

> **Règle de travail :** Lorsqu’il existe plusieurs variantes, utiliser la forme française privilégiée indiquée ici. Les autres formes ne sont admises que comme alias de recherche ou dans une citation.

---

## Règles essentielles

- Conserver à l’identique les noms de produits, de fonctions et d’accessoires protégés.
- Utiliser « mémoriser » pour les accessoires WiPro, NFC et radio ; réserver « appairer » au Bluetooth.
- Distinguer l’armement/désarmement du verrouillage/déverrouillage.
- Toujours distinguer la sirène du klaxon du véhicule.
- Ne pas reprendre l’abréviation allemande ZV ; écrire « verrouillage centralisé ».
- Conserver les références, numéros de série, commandes SMS, broches, couleurs de câble, unités et abréviations.

## Termes à ne pas confondre

| Termes | Différence |
|---|---|
| `safe.lock / code tournant` | safe.lock désigne la logique de sécurité THITRONIK. Le code tournant décrit la génération de la clé d’origine. |
| `attaque par rejeu / protection contre le rejeu` | L’attaque par rejeu est le scénario d’attaque ; la protection contre le rejeu est la fonction de défense. |
| `mode de mémorisation / mode d’appairage` | La mémorisation concerne WiPro, la NFC et les accessoires radio. L’appairage concerne le Bluetooth. |
| `armer / verrouiller` | Armer active la surveillance ; verrouiller actionne le verrouillage centralisé. |
| `désarmer / déverrouiller` | Désarmer arrête la surveillance ; déverrouiller ouvre le verrouillage centralisé. |
| `sirène / klaxon du véhicule` | La sirène est un dispositif d’alarme dédié ; le klaxon est l’avertisseur d’origine du véhicule. |
| `module NFC / KeyCard, KeyTag, KeyStrap` | Le module NFC est le lecteur. KeyCard, KeyTag et KeyStrap sont les supports d’accès. |
| `alarme panique / alarme intrusion` | L’alarme panique est déclenchée volontairement ; l’alarme intrusion résulte d’une cause détectée. |
